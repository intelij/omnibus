# Demo Data

`php artisan migrate:fresh --seed` produces a complete, immediately usable system. Everything below is created by `DatabaseSeeder` — all dates are relative to "now", so trips stay bookable on any day you seed.

## Credentials (development only — production seeding is blocked)

| Account | Email | Password | Role |
|---|---|---|---|
| Platform admin | `admin@transithub.test` | `password` | `platform_super_admin` (cross-tenant) |
| ZE admin | `admin@zimbabweexpress.test` | `password` | `tenant_admin` |
| BS admin | `admin@bulawayostar.test` | `password` | `tenant_admin` |

Each tenant also gets `owner@`, `agent@`, `finance@`, `support@` at the same domain pattern, same password. All seeded users are `active` and email-verified; the seeder refuses `APP_ENV=production` unless `SEED_DEMO_IN_PRODUCTION=1` is set deliberately.

## Tenants

- **Zimbabwe Express** (`zimbabwe-express`) — the default `X-Tenant` slug in `web/.env.local`
- **Bulawayo Star Coaches** (`bulawayo-star`)

Both: USD, Africa/Harare, `payment_methods: [cash, card, ecocash]`, full booking rules.
